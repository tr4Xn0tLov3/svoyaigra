# ◆ Своя Игра Онлайн

Сетевая веб-версия классической телевикторины **«Своя игра»** для компании друзей. Интерфейс и паки вопросов публикуются как статический сайт на GitHub Pages; для комнат используется WebSocket-сервер Cloudflare Worker с Durable Object (`cloudflare-worker/`). Ведущая вкладка сохраняет резервную копию игрового состояния в браузере, чтобы восстановиться после обычного обновления страницы.

---

## ✨ Возможности

- **Онлайн-комнаты по ссылке через WebSocket-сервер** — ведущий создаёт комнату и отправляет ссылку вида `https://ваш-ник.github.io/svoya-igra/?room=K7M4P`. Сервер ретранслирует действия и индивидуальные представления вопросов между ведущим и игроками, не полагаясь на прямое WebRTC-соединение.
- **Полная классика + Весёлые пакости для друзей**:
  - **📈 3 уровня ставок для камбэка**: Уровень 1 — от **100** (`100–500`), Уровень 2 — от **500** (`500–2500`), Уровень 3 — от **1000** (`1000–5000`), чтобы даже обнулённый или отстающий игрок мог мощно отыграться!
  - **😈 7 весёлых модификаторов-пакостей** против соперников:
    - `nothing_personal` — **🕶️ Ничего личного**: сжечь весь положительный счёт выбранного соперника в `0`;
    - `mute_player` — **🤐 Кляп на раунд**: заклеить рот и отключить кнопку ответа выбранному игроку на текущий вопрос;
    - `upside_down` — **🙃 Вверх дном**: перевернуть текст, мемы и кадры у жертвы вверх ногами на 180°;
    - `mud_screen` — **🧽 Грязь в экран**: заляпать экран соперника — пока он не протрёт стекло 8 нажатиями, вопрос размыт;
    - `runaway_buzzer` — **🤡 Убегающая кнопка**: кнопка «ОТВЕТИТЬ» у жертвы 3 раза с хохотом упрыгивает из-под пальца или `Пробела`;
    - `score_steal` — **🧛 Грабёж баллов**: откусить 25% счёта богача прямо в свой карман;
    - `cursed_mark` — **💣 Чёрная метка ×2**: двойной куш `+2×` за верный ответ, но и двойной штраф `−2×` за ошибку (можно кинуть сопернику или рискнуть на себя!);
  - **🐈 Кот в мешке**, **🔨 Вопрос-аукцион** (с торгами и «Ва-банк!»), **🛡️ Вопрос без риска** и **🏆 Финальный раунд** (вычёркивание тем, секретные ставки, 60 сек на ответ и пошаговое вскрытие)!
  - **💡 Система подсказок**: личные подсказки игроков на партию (**💡 Наводка**, **🔤 Первые буквы**, **🛡️ Страховка от минуса**) + кнопка ведущего **«💡 Подсказка всем (H)»**.
  - **🎵 Фирменные рубрики для компании**: пак вечеринки состоит из **3 уровней по 6 тем и 30 вопросов**. Есть музыка (аудио + «🎹 Только мелодия»), фотораунд «Узнай музыканта», «Крысало» и другие словесные склейки с иллюстрациями, суд над бытовыми предметами, мемы, Wild Rift, «Торт ли это?», звери на работе и абсурдная техподдержка. Для фото музыкантов лицензии и авторы указаны в `packs/media/images/music-quiz/CREDITS.md`; новые иллюстрации лежат в `packs/media/images/absurd/`.
- **Защита от фальстарта и сигнальная рамка** — три режима кнопки: *сразу*, *после авто-паузы на чтение* или *по сигналу ведущего в голосовом чате* (как в SIGame).
- **Хранение вопросов в JSON-файлах репозитория (`packs/`)** + встроенный на сайте **Конструктор JSON-паков** для быстрой сборки новых игр.
- **Поддержка медиа** — картинки (`svg`, `png`, `jpg`), аудио (`mp3`, `m4a`, `ogg`) и видео (`mp4`, `webm`), а также синтезированные студийные звуковые эффекты (Web Audio API).

## 🛰️ WebSocket-сервер для комнат (Cloudflare)

GitHub Pages публикует только сайт и не запускает серверную логику. Для комнат добавлен Cloudflare Worker с Durable Object: Durable Objects поддерживают WebSocket-комнаты и могут сохранять соединения при hibernation [документация](https://developers.cloudflare.com/durable-objects/best-practices/websockets/).

1. Загрузите папку `cloudflare-worker/` в корень репозитория.
2. В Cloudflare откройте **Workers & Pages → Create application → Connect to Git** и выберите GitHub-репозиторий `svoyaigra` и ветку `main`.
3. Укажите корневую папку проекта Worker `cloudflare-worker/`, команду сборки `npm install` и команду публикации `npm run deploy`. Имя Worker должно совпасть с `name` в `cloudflare-worker/wrangler.toml`: `svoya-igra-realtime`.
4. После публикации проверьте `https://svoya-igra-realtime.<ваш-subdomain>.workers.dev/health`. Только если этот адрес открывается на устройстве ведущего и на компьютере игрока, укажите соответствующий WebSocket-адрес в `js/config.js`: `wss://svoya-igra-realtime.<ваш-subdomain>.workers.dev/ws`.
5. Дождитесь обновления GitHub Pages, перезагрузите сайт на обоих устройствах и создайте новую комнату.

**Пока Cloudflare Worker не проверен с обоих устройств, оставляйте текущий адрес `js/config.js` без изменений.** Резервная копия состояния ведущего хранится в браузере на том же устройстве; не очищайте данные сайта, если нужно восстановить комнату после обновления страницы.

## 🚀 Как выложить сайт на GitHub Pages

### Способ 1. Прямо в браузере (без консоли и Git)
1. Зайдите на [github.com/new](https://github.com/new) и создайте **Public** репозиторий (например, `svoya-igra`).
2. Нажмите **uploading an existing file** и перетащите туда все файлы и папки проекта (`index.html`, `.nojekyll`, `css/`, `js/`, `packs/`, `README.md`), затем нажмите **Commit changes**.
3. Перейдите во вкладку **Settings → Pages** вашего репозитория.
4. В разделе **Build and deployment → Source** выберите **Deploy from a branch**, ветку **`main`** и папку **`/ (root)`**, нажмите **Save**.
5. Через ~1 минуту сайт будет доступен по адресу:
   `https://<ваш-логин>.github.io/svoya-igra/` 🎉

### Способ 2. Через терминал (`git`)
```bash
git init
git add .
git commit -m "Initial commit: Svoya Igra Online"
git branch -M main
git remote add origin https://github.com/<ваш-логин>/svoya-igra.git
git push -u origin main
```
Затем включите **Settings → Pages → Branch: `main` / `(root)`**.

## 📦 Как добавлять свои паки вопросов в репозиторий

Все паки лежат в папке `packs/`, а их список на главной странице берётся из `packs/index.json`.

1. **Самый простой путь**: нажмите на сайте кнопку **«🛠️ Конструктор паков (.json)»**, заполните раунды, темы, вопросы и финал, затем нажмите **«💾 Скачать .json»**.
2. Загрузите скачанный файл (например, `friday-party.json`) в папку `packs/` вашего GitHub-репозитория.
3. Добавьте описание пака в массив `"packs"` внутри файла `packs/index.json` (готовый кусок кода конструктор показывает прямо внизу окна!).

## ⌨️ Горячие клавиши во время игры

- **У игроков**: `Пробел` — нажать кнопку **«ОТВЕТИТЬ!»**
- **У ведущего**:
  - `Пробел` — активировать кнопку (в режиме чтения) / вернуться на табло после показа ответа
  - `1` или `Y` — **✅ Верно**
  - `2` или `N` — **❌ Неверно**
  - `P` — пауза / продолжение таймера
